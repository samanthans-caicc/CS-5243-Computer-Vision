# Assignment 1: Image Representation and Visual Exploration

**Version:** A1-2026.1 · **Environment:** 2026.1 · **Individual** · **100 points**

A1 investigates image and video representations across array layouts, channel orders, color spaces, datatypes, intensity ranges, spatial selections, and encodings. Assignment tasks and point values are in `A1.ipynb`; general installation and course workflow are in the repository README.

## A1 workflow

From any terminal directory, activate the environment and launch the notebook by path:

```bash
conda activate cs5243
jupyter lab /path/to/cs5243-A1/assignments/A1/A1.ipynb
```

Run preflight before implementation:

```bash
python /path/to/cs5243-A1/scripts/validate_submission.py --assignment A1 --preflight
```

Complete `A1.ipynb` and `src/student_code.py` without adding packages for required work. Execute the final notebook, export `A1.html`, validate, and package using the commands in Section 10 of the notebook. The final Canvas checks are in `CANVAS_CHECKLIST.md`.

## Artifact formats

Additional useful columns are allowed in CSV files.

- `image_metadata.csv`: `filename, shape, height, width, channels, dtype, minimum, maximum, mean, bytes`
- `timing.csv`: `method, median_ms, repeats, outputs_equal`
- `experiment_metrics.csv`: long-form records with `experiment, method, condition, metric, value, units`

Maintain one cumulative `experiment_metrics.csv`. Add records from later experiments without deleting or overwriting records from earlier sections.

`video_metadata.json` must contain:

- `input` and `output` objects, each with `path`, `width`, `height`, `fps`, `frame_count`, `duration_seconds`, and `codec`;
- `read_back.valid`; and
- `read_back.checks` with `resolution`, `fps`, and `frame_count` Boolean results.

## Graded function contracts

- Crops and replaced rectangles must have positive dimensions, stay inside the image, and leave the input unchanged.
- A contact-sheet call contains either all 2-D grayscale or all three-channel RGB `uint8` images. Place each image at the top-left of its cell with an 8-pixel outer border and gutter.
- Brightness functions use NumPy nearest-even rounding (`np.rint`) before clipping and conversion to `uint8`.
- `transform_frame` horizontally flips an RGB frame and multiplies its red channel by `0.65`, returning an `HxWx3 uint8` array.
