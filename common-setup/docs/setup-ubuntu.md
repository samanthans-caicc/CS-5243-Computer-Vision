# Ubuntu setup notes

Follow the root [first-time setup](../README.md#first-time-setup) using the current Linux Miniforge installer.

- A desktop browser is needed for local JupyterLab; FFmpeg is supplied by the environment.
- Keep the repository in a user-writable location and quote paths containing spaces.
- For a remote Ubuntu host, use an institution-approved connection method and do not expose Jupyter publicly.
- Do not paste `/home/...` or `/mnt/...` paths into submitted notebooks or source files.

The everyday workflow, update command, export command, and Canvas checklist are centralized in the root README. See [troubleshooting](troubleshooting.md) before changing channels or installing extra packages.
