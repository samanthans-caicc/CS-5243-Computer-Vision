# A3 assets

`dataset/visual_patterns.npz` is a deterministic, balanced six-class RGB recognition dataset generated by course staff. It contains 720 training, 180 validation, and 180 testing images at 64×64 pixels. Splits are fixed and disjoint; `metadata/dataset.json` records class order and counts.

`models/` contains the official torchvision ImageNet weights for MobileNetV3-Small and EfficientNet-B0 so required transfer-learning work runs without downloads. Load these local state dictionaries rather than requesting weights from the network.
