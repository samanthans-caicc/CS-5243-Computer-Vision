# A2 assets

Image-enhancement assets for A2. Most are generated deterministically by course staff (CC0 1.0); two blend pairs are real photographs retained from this course's legacy materials (see `ATTRIBUTION.md`). The set contains an odd-sized grayscale test pattern, a color scene, two controlled noisy observations, five aligned blend pairs with different mask geometry (a soft vertical seam, a circular spot, and a diagonal seam over synthetic scenes, plus a hard vertical seam and a hard circular seam over real fruit photographs), an underexposed contrast source, and a difficult high-frequency case. See `metadata/assets.json` for dimensions and grouping and `SHA256SUMS` for integrity.

The assignment does not download data at execution time.
